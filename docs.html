TelStore documentation

Everything needed to deploy, configure and run your own TelStore shop bot on a Linux server.

Prerequisites

Requirements

TelStore runs directly on your own infrastructure. Before installing, ensure your host environment meets these requirements:

  • Operating System: Ubuntu 22.04 LTS or Ubuntu 24.04 LTS
  • Hardware: 1 vCPU and 2 GB RAM (a standard small Linux VPS)
  • Python: Python 3.11 or newer
  • Telegram Bot Token: Created via @BotFather
  • Wallet Address: A crypto wallet address (BSC / Tron) to receive direct customer payments
Setup

Install

Follow these numbered steps to deploy TelStore on your server:

  1. Download the source archive

    Get TelStore-Bot.zip from your purchase — the download link is on the order page and in the delivery email.

    The source code is not in the public GitHub repository. That repository holds the documentation only.

  2. Upload and unpack

    Copy the archive to your server over SSH or SFTP, then unpack it:

    unzip TelStore-Bot.zip -d /opt
cd /opt/telstore

    This lands you inside telstore/, which contains the scripts/ subfolder — run all subsequent commands from this project root.

  3. Preview the installer

    The installer supports a dry run so you can see what will change:

    bash scripts/install_telstore.sh --dry-run
  4. Run the installer 
    sudo bash scripts/install_telstore.sh --create-service

    --create-service writes the systemd unit and needs root. Run the whole command with sudo if your shell is not root.

  5. Start and check the bot

    The installer deliberately does not start the bot — start it explicitly:

    sudo systemctl start telstore-bot
sudo systemctl status telstore-bot

    To remove the deployment cleanly later, run sudo bash scripts/uninstall_server.sh.

Environment

Configure

TelStore reads its configuration from a .env file in the project root. Populate this file with your credentials:

TELEGRAM_BOT_TOKEN=your_bot_token_here
CRYPTO_ADDRESS=0xYourWalletAddressHere
MANUAL_CHAIN=BSC
NOWPAYMENTS_API_KEY=
COINGATE_AUTH_TOKEN=
COINGATE_ENABLED=0
PRICE_USD=5
OWNER_CHAT_ID=your_chat_id_here
WEBSITE_URL=https://example.com
SUPPORT_URL=https://t.me/yourusername

Configuration keys explained:

  • TELEGRAM_BOT_TOKEN — The secret API token provided by @BotFather when you register your bot.
  • CRYPTO_ADDRESS — Your wallet address receiving direct on-chain customer payments.
  • MANUAL_CHAIN — BSC for BEP-20 tokens, or TRON for TRC-20.
  • NOWPAYMENTS_API_KEY — Your API key from NOWPayments if accepting card payments or extended coins.
  • COINGATE_ENABLED — Leave at 0 until your CoinGate account has passed KYC.
  • OWNER_CHAT_ID — Your numerical Telegram account ID, granting full admin panel privileges inside the bot.
  • WEBSITE_URL — Where the Official Website button in the bot sends customers. Must start with https://. Leave it empty to hide the button's link.
  • SUPPORT_URL — Where the Support button sends customers. Must be an https://, tg:// or t.me/ link, or an @username.
Product Management

Add a product

Products are created entirely within Telegram without needing a web dashboard. The shortest path is:

Admin Menu → Add Product → the eight-step wizard:

  1. Open the bot in Telegram and launch the Admin Menu.
  2. Tap Add Product to initialize the interactive wizard.
  3. Enter the Product Title.
  4. Provide the Product Description.
  5. Select or create the Product Category.
  6. Choose the delivery type: Digital File or VIP Channel Access.
  7. Upload the digital file or specify the invite link for your private Telegram channel.
  8. Set the Price and access duration (for VIP access), then review and confirm to publish the product to your live shop catalog.
Diagnostics

Troubleshooting

Common issues and resolutions when running TelStore:

  • Bot silent: Check that your TELEGRAM_BOT_TOKEN matches your @BotFather settings exactly. Verify that the bot service process is actively running on your VPS and check system service logs for errors.
  • Payment not confirming: On-chain confirmations require time to clear on the blockchain network (two confirmations are enforced). Confirm that the buyer sent the exact transaction amount to your designated wallet address on the correct network (BSC or TRON).
  • VIP invite fails: The bot must be added to your VIP channel or group as an Administrator with permissions to create invite links and add subscribers.

Still stuck? Email TelStorebot@gmail.com with your server's OS version, the exact command you ran, and the error output.

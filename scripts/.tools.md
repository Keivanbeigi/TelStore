## How to use when mid-task
- **Parse a JSON API response** → `curl ... | jq '.result[0].title'`
- **Find code fast** → `rg "TODO" scripts/`
- **Package the sale bundle** → `"C:\Program Files\7-Zip\7z.exe" a bot-bundle.zip ...`
- **Install another Windows tool** → `winget install <Name>`

> Note: 7-Zip, jq, ripgrep need a fresh terminal (PATH reload) after install.
